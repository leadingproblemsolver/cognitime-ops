# Human Ownership Sprints

Complete these before claiming implementation ownership.

## Sprint 1 — Reconstruct

Explain without reading the README:

```text
input format
→ normalization
→ scoring
→ phase grouping
→ metrics
→ rendering
→ storage
→ export
```

Write result to:

```text
evidence/human-ownership/architecture-reconstruction.md
```

## Sprint 2 — Modify

Make one meaningful change, such as:

- Add a new work item field.
- Change scoring weights and explain why.
- Add a new export section.
- Add a printable view.

Write result to:

```text
evidence/human-ownership/feature-change.md
```

## Sprint 3 — Debug

Introduce or diagnose one failure, for example:

- malformed line parsing
- export issue
- localStorage import failure
- ICS event formatting

Write result to:

```text
evidence/human-ownership/debugging-record.md
```

## Sprint 4 — Defend

Defend:

- why v1 is local-first
- why no AI provider is required
- why localStorage is acceptable for validation
- why GitHub Pages is the first deployment target
- what claims remain unsupported

Write result to:

```text
evidence/human-ownership/technical-defense.md
```
